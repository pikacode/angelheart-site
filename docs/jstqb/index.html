JSTQB試験対策 問題集・模擬試験・シラバス解説

JSTQB認定テスト技術者資格（ISTQB）の試験対策アプリのWeb版です。Foundation Level（基礎レベル・FL・CTFL）、Advanced Level テストマネージャ（テストマネジメント・AL TM・CTAL-TM）、Advanced Level テストアナリスト（AL TA・CTAL-TA）の資格勉強に、パソコンやスマホのブラウザからそのまま使えます。

  • JSTQB 問題集・練習問題：章・節ごとに出題、選択肢ごとの解説と回答履歴つき
  • JSTQB 一問一答：テスト技法・テスト設計・テストプロセス・品質保証など、ソフトウェアテストの知識を1問ずつ確認
  • JSTQB 模擬試験：本番と同じ問題数・試験時間・章配分。スコアの推移と合格の見込みを表示
  • JSTQB 過去問：本試験の過去問は公開されていないため、シラバスの出題範囲に沿った独自問題で対策
  • JSTQB シラバス解説：Foundation Level シラバス v4.0、テストマネージャ v3.0、テストアナリスト v4.0 を章・節ごとに解説。用語の確認にも
  • JSTQB 勉強方法：スキマ時間にスマホ・パソコンで。iPhone・iPadアプリ（App Store）と学習データを同期
  • JSTQB 難易度・合格率が気になる人も、模擬試験で合格ラインに届くか確認
  • ソフトウェアテスト初心者、QAエンジニア、テストエンジニアの資格取得・独学に
  • IT資格・ソフトウェアテスト資格の対策アプリ。iPhone・iPad版はApp Storeで配信中
  • 一部の章と模擬試験は無料。全機能は試験ごとの買い切りで、月額料金なし
